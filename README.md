# CSV to JSON Converter

A lightweight Python script that converts flat CSV files into structured JSON objects. This is particularly useful for preparing datasets for APIs, web applications, or formatting data for AI model evaluation.

## Features
- Reads standard CSV files with headers
- Outputs clean, indented JSON
- Handles UTF-8 encoding safely
- Includes basic error handling for missing files

## How to use
1. Place your `input.csv` file in the same directory as the script.
2. Run the script using Python:
   ```bash
   python csv_to_json.py
